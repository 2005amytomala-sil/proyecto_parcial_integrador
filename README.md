# Detector de intrusiones de red (UNSW-NB15)

Proyecto integrador de Inteligencia Computacional: clasificación binaria de tráfico de red,
optimización con algoritmo genético y prototipo en Streamlit.

Todo el código, los datos, los resultados y las instrucciones de uso están en la carpeta
[`proyecto-ic`](proyecto-ic/README.md).

- Prototipo: `proyecto-ic/app/app.py`
- Modelo final: `proyecto-ic/models/pipeline_final.joblib`
